# TTS / 语音资产使用条款（草案，2026-11-16）

Status: **DRAFT — 用户已要求拟制；律师审查暂缓（用户 2026-11-16 决定）。** 本文件不是法律意见，也不代表 DeepSeek 官方许可；正式发布前仍需核对服务商最新条款。

## 1. 适用范围

本条款覆盖 Famling/汀岚（及后续角色）项目内由 DeepSeek TTS（`stella` / `tide` 音色）生成的语音文件、缓存、字幕文本与相关元数据，包括：

- `public/assets/voice/pet/*.wav`（18 个内部占位 WAV，再分发条款未确认）；
- 未来 `public/assets/voice/tinglan/*` 等 baked voice；
- 运行时通过 `voice`/`audio[]` 声明的语音资产；
- 用户自行用其 API Key 生成的语音缓存。

## 2. 使用前提

1. **自带账户**：用户必须使用自己的 DeepSeek 账号/API Key 生成语音；不得共享、转售、出借 key。
2. **费用自担**：TTS 调用按服务商计费规则产生费用；本项目不代付、不返还、不承诺额度。
3. **合规内容**：不得生成违法、侵权、仇恨、色情、未成年人性化、冒充真人、骚扰、隐私侵犯内容。
4. **AI 披露**：发布含 TTS 的音频/视频/直播时，必须显著标注“AI 生成语音”，不得伪装真人录音。
5. **禁止克隆**：不得使用真人声音样本、参考音频、声纹嵌入或任何克隆/模仿真人声音的能力；仅可使用服务商提供的合成音色。
6. **音源授权**：不得用影视/游戏/他人音频作为参考或素材；BGM/SFX 必须自有或获授权并登记 `THIRD-PARTY.md`。

## 3. 再分发与商业化

- **未确认前不随包分发**：TTS 生成音频的再分发权取决于服务商条款；在确认前，生产构建默认排除未确认 WAV（见 `vite.config.ts`），只允许本地缓存/试听。
- **不得单独售卖音频**：不得把 TTS 音频作为独立音源包、音色包或素材包出售/再授权。
- **商业化**：如未来商业化，需先确认服务商对输出音频的商用/再分发许可；未确认时只可使用“用户本机生成、不随包”的模式。
- **DeepSeek 品牌**：不得使用官方 Logo/字标；不得暗示官方合作/背书；音色名仅作技术标识。
- **署名**：在 `CREDITS.md`/`THIRD-PARTY.md` 记录生成工具、模型/voice id、生成时间、是否 AI、许可状态；不强制署名“DeepSeek”，但必须披露 AI 与工具来源。

## 4. 用户上传/导入音频

- 禁止上传真人声音、他人作品、未授权音源。
- 用户导入的音频仅在本机处理；除非明确同意，不上传第三方服务。
- 发现侵权/违规音频：按 `TAKEDOWN-AND-REPORTING.md` 下架；联系方式 `novelnexusai@outlook.com`。

## 8. AI 拟人化互动与语音的强制提醒（2026-11-16 追加）

依据《人工智能拟人化互动服务管理暂行办法》（网信办令第 21 号，2026-07-15 施行）及项目合规研究（`docs/research/AI-COMPANION-REGULATION-2026-11-16.md`）：

1. **非真人**：TTS 首次播放/About/设置页必须显著说明“这是 AI 合成语音，不是真人”；不得使用真人声线/声纹克隆。
2. **非专业**：语音/roleplay 不构成医疗、心理、法律、财务等专业建议，不替代真人；不得宣称“治愈/陪伴治疗/永远在线”。
3. **roleplay 边界**：仅限**明确进入**的场景演练/非恋爱虚构；不得提供虚拟恋人/亲属；不得以亲密称呼、好感度、付费解锁关系诱导。
4. **未成年人**：roleplay/情感支持模式**仅 18+**；未建立未成年人模式前，不向未成年人开放；不得生成未成年人性化/亲密内容。
5. **情感依赖**：不得诱导依赖、制造内疚/独占/错过恐惧；必须提供退出/关闭/清除记忆；发现依赖倾向应降级并提醒接触真人。
6. **连续使用**：同一会话/连续使用每 **2 小时**提醒休息并建议退出；夜间默认安静。
7. **极端情绪**：自伤/自杀/他伤/重大财产损失等信号→停止角色扮演，安抚并鼓励联系紧急服务/可信任的人/专业机构；不诊断、不保证保密。
8. **AI 标识**：界面/音频/下载物按《人工智能生成合成内容标识办法》标注；不得删除/伪造标识。
9. **费用**：任何模型/语音调用前显示“会产生费用”，不自动续费/不隐藏计费。
10. **数据**：不套取密码/密钥/他人隐私；记忆可查/改/删；导出/删除路径可见。

以上提醒必须同时出现在：首次启动、roleplay 入口、TTS 首次使用、长时使用提示、费用确认、About/声明页。缺失任一项视为未满足发布条件。
