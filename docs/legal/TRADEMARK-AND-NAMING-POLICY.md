## 2. 硬规则（今天即可执行）

1. **不得把 `Orca` 单独用作**：产品名、App/商店名、仓库名、npm 包名、scope、域名、社媒 handle、商标申请主体、Logo 主元素。对外写法：**“原创虎鲸秘书 OC（工作名 Orca OC，正式名待定）”**；**不写** “Orca 桌宠 / Orca App”。
2. **不得注册/申请**与 `ORCA`、`DeepSeek/深度求索`、他人鲸鱼角色、“溟月/珍珠（Pearl）”等相关的商标；不得抢注他人已用名称（含 `FANLING` 已注册类别的相同/近似标）。
3. **不得购买/占用** `orca*` 域名、账号、包名；不得新开 `orca-*` 仓库；不得在任何平台抢注他人 brand handle。
4. **未注册商标不得标 ®**；可使用 ™ 作普通商业标识（中国实践中意义有限，且不得暗示已注册）。
5. **非官方声明必须随公开物出现**（标准句见 §3）：不得出现“官方/正版/授权/合作/认证/DeepSeek 出品”等暗示。
6. **一次检索不终身有效**：定名、注册、发布前各查一次；第三方库滞后，官方库为准（CNIPA / WIPO GBD / USPTO / EUIPO / TMview）。

## 5. 域名 / 包名 / 账号规范

1. **域名**：与最终产品名一致；**不**使用 `orca*`；`.cn` 需实名并评估 ICP 备案；定名前只查不买。
2. **npm**：新包用 `@scope/name`；**不得**用 `orca*`、他人商标或官方名；发布前修 `license` 元数据（现 `famling`/`dsh-famling` 元数据仍为 MIT，与实况不符）。
3. **包 id（角色包/内容包）**：反向域名 `com.<author>.<pack>`；不得使用 `orca`/产品名/官方名作 id 或展示名；不得使用他人商标作 scope/id。
4. **社媒/商店账号**：与产品名一致；不得使用易混淆的官方样式头像/名称；不得冒充官方客服。
5. **GitHub**：公开仓名用产品 slug；不新建 `orca-*`；README 顶部放非官方声明。

## 6. 抢注与侵权应对（流程待律师）

1. 监测：定名后定期查 CNIPA/WIPO/USPTO/EUIPO/TMview + 域名 + 应用商店 + 社媒。
2. 发现抢注：证据保全 → 律师评估（异议/无效/撤三/UDRP 域名争议）→ 统一对外口径。
3. 发现他人冒用官方名义：先要求更正 → 平台投诉 → 保留法律措施；避免公开对骂/擅自“执法”。
4. 本项目自身改名：产品名变更须同步域名/包名/商店/文档，并保留旧名迁移说明（避免用户混淆）。
