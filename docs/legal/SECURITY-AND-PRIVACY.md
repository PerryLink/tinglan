## 1. 数据清单（2026-11-15 实测）

| 数据 | 存放 | 用途 | 保留 | 是否外传 |
|---|---|---|---|---|
| 桌宠存档（名字/亲密度/状态/物品） | 本地 `localStorage`，**加密**（`src/pet/crypto.ts`）；有 `.bak` 备份槽 | 恢复宠物状态 | 用户删除或重置前 | 否 |
| 音量/显示等偏好 | 本地 `localStorage` 明文（非敏感） | 设置 | 同上 | 否 |
| 崩溃环形缓冲（≤50 条，含 message/stack） | 内存/本地 | 本地排障 | 会话/滚动覆盖 | **默认否**；可配置 Sentry（见 §4） |
| 麦克风音频 | 内存（录音≤60 s）→ Rust 代理 → ASR | 语音识别 | **不持久化**（≤8 MiB 上限） | **是**：发往所选 ASR 服务（当前 DeepSeek） |
| 语音识别文本 | 内存/界面 | 对话与触发动作 | 不落盘（除用户保存的对话内容） | 可能随对话发往 TTS/LLM 服务 |
| TTS 文本 | 内存；每日字符预算（默认 2000/日） | 读出角色台词 | 不落盘 | 是（若用云 TTS） |
| 对话/记忆内容 | 本地（记忆/存档；加密与否视实现，`crypto.ts` 已用于存档） | 连续性 | 用户可清除（有确认提示） | **默认否**；若用户配置云对话/TTS 则随文本外传 |
| Advisers 快照（matter/commitment/routine） | 本地只读 JSON | 生成桌宠简报 | 不复制原文 | 否（仅本地渲染） |
| 遥测 | —— | —— | **默认关闭**，无遥测服务 | 否 |

> 原则：**本地优先、最小必要、默认不联网、不训练**（不使用用户数据训练模型）。

## 2. 用户控制（必须提供，UI 可发现）

1. 清空/导出存档；关闭语音输入与语音输出；关闭记忆；关闭崩溃上传（若启用 Sentry）；删除全部本地数据。
2. 首次使用麦克风/云语音/记忆前**明确告知**并取得同意；拒绝后功能降级但不影响基础使用。
3. 数据删除请求渠道：`novelnexusai@outlook.com`（响应目标 15 个工作日，非法定承诺）。
4. 未成年人：不面向儿童设计；若实际面向未成年人，须家长同意与内容限制（待律师）。

## 3. 隐私红线（工程不得违反）

1. **不得**上传存档、记忆原文、Advisers 事项详情、文件系统内容；不得采集剪贴板/键击/屏幕。
2. **不得**把 `secrecy` 标记的事项显示在公共可见界面/日志（Advisers 秘密字段必须过滤）。
3. 音频/文本发往第三方前，须在 UI 说明“将上传至 X 服务用于识别/合成”，并允许关闭。
4. API key 只存 Rust 侧/系统凭据库，**禁止**进前端、日志、包、仓库、错误上报。
5. 日志与崩溃信息不得含个人信息/密钥/原文对话。
6. 默认**无遥测**；如需遥测，必须 opt-in + 清单化 + 可关闭 + 匿名化。

## 4. 遥测与崩溃上报（opt-in）

- 现状：本地崩溃环形缓冲（`src/observability.ts`，**无网络**）；Sentry 仅在显式配置 `enabled + dsn` 时初始化。
- 要求：默认关闭；开启时明确列出上报内容（错误栈、版本、OS，不含用户内容）；提供关闭开关；第三方隐私政策链接。
- 若未来接入遥测：先更新本文 + 隐私政策 + 首启同意，再上线。

## 5. 安全基线

1. 内容包/角色包：Ed25519 签名 + 逐文件 sha256；未签名默认拒绝；纯数据、不执行脚本；路径遍历/zip 炸弹/配额校验（见 [DLC-AND-PLUGIN-TERMS](./DLC-AND-PLUGIN-TERMS.md)）。
2. 应用：CSP、禁用 `eval`/远程代码、最小权限（Tauri capabilities）、依赖锁定与定期更新。
3. 发布卫生：不打包 `<private-keys>/`、私钥、`refs/`、Steamworks SDK、第三方安装器；构建可复现（lockfile）。
4. 供应链：npm/Rust 依赖审计；签名密钥离线保管与轮换（待落地）。
5. 本地文件读取（如 Advisers）只读、限定路径、失败静默不崩溃。

## 7. 安全事件响应

1. 发现/报告 → 2. 初判影响面（数据/用户/供应链）→ 3. 临时缓解（下架包、轮换密钥、关闭功能）→ 4. 修复与验证 → 5. 通知（受影响用户/平台/机关，法定期限依 PIPL 等，待律师）→ 6. 复盘与文档。
2. 不得隐瞒或延迟通知以“保声誉”；不得用删除数据的方式“处理”事件。
3. 涉及用户数据泄露：保留证据、评估通知义务、提供补救建议。

## 8. 合规提示（待律师）
