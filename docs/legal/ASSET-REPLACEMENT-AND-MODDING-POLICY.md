# 替换与改模政策：动作 / 声音 / 形象 / 行为 / UI — 草案

> **状态：DRAFT · 2026-11-15 · 非法律意见。** 待用户 + 律师确认。本文规定“对本项目角色/桌宠做替换与改模”时哪些可以做、哪些必须保留、哪些绝对禁止；**不改变**各素材自身的许可。
> 适用载体（2026-11-15 实测）：FCI 角色包 `character.json`（tags/behaviors/render/atlas/audio/expressions）、内容包 `content.json`、资源目录 `public/assets/`；渲染格式 `pixel-hero | pixel-micro | hd-chibi`（第一方）。**包内永不执行脚本。**
> 关联：[DLC-AND-PLUGIN-TERMS](./DLC-AND-PLUGIN-TERMS.md) · [FANWORK-POLICY](./FANWORK-POLICY.md) · [AI-CONTENT-POLICY](./AI-CONTENT-POLICY.md) · [CONTENT-POLICY](./CONTENT-POLICY.md) · 模板 [TEMPLATES](./DECLARATION-TEMPLATES/TEMPLATES.md)。

## 1. 替换矩阵（先看这一张表）

| 可替换项 | 载体 / 字段 | 允许 | 条件与必须声明 |
|---|---|---|---|
| 动作/动画帧 | `art/frames/<tag>_*.png`、`art/atlas/*.webp`、`character.json.atlas` | ✅ | 自有或已授权素材；保留 tag 语义/锚点/画布约束；注明作者、许可、修改说明 |
| 行为参数 | `character.json.behaviors`（声明式 JSON） | ✅ | 只改数据；不得注入脚本、不得改宿主安全/付费/遥测逻辑 |
| 表情/面部层 | `face/*.png`、`expressions`（预留字段） | ✅（预留） | 同“形象”规则；不得性化/未成年人不当呈现 |
| 声音/SFX | `audio/sfx/*.ogg` 或 `.wav`、语音包 | ⚠️ 有条件 | 自有录制或已授权音源/TTS；**禁真人声音克隆**；合成语音须披露 |
| 形象/立绘/模型 | `character.json` + 图集/模型文件 | ⚠️ 有条件 | 自有/CC BY-NC-SA/已授权；**禁他人 IP**；改官方角色须注明修改、不得称官方版 |
| 文案/i18n | 本地化文件 | ✅ | 不得歪曲原意、不得塞入广告/违法内容、保留署名 |
| UI 皮肤/主题 | 自有 CSS/图资源 | ⚠️ 有条件 | 不得遮挡/移除声明、AI 标识、安全与隐私提示、商标性 Logo |
| 渲染器/插件 | 二进制/代码 | ❌ | 仅第一方构建期 allowlist；第三方可执行扩展不受理 |
| 宿主程序本体 | 应用代码/签名 | ❌ | 不得反编译修改分发；不得破坏签名/校验 |

## 2. 动作替换

1. 允许：自制帧/图集、调整节奏、新增 tag（须声明能力与 `minRuntime`）；保持画布尺寸、锚点、透明通道规范。
2. 禁止：挪用他人游戏/动画/影视的动作帧或动捕数据；用反向工程提取本项目未公开的图集；用 R18/暴力动作冒充官方动作集。
3. 必须：包内写明“动作来源（自绘/AI 辅助/授权）+ 作者 + 许可 + 修改说明”；不得删除原角色包的作者与 AI 披露。
4. AI 辅助生成的动作帧按 [AI-CONTENT-POLICY](./AI-CONTENT-POLICY.md) 披露（`ai.status` + 工具），不得冒充手绘。

## 3. 声音替换（风险最高，逐条看）

1. **允许**：本人录制且本人同意上传；明确许可的音效库；许可允许再分发的 TTS 模型+音色（**同时**核对模型许可与音色条款，两者缺一不可）。
2. **禁止（硬红线）**：
   - 未经**书面**同意的**真人声音克隆**（含名人、同事、网友、“我朋友同意”口头说辞）；
   - 从影视/动画/游戏/VTuber/有声书提取音频；
   - 使用他人已发布 TTS 音色/语音包（除其条款明确允许再分发）；
   - 用语音冒充官方客服/真人角色/真实人物；
   - 儿童声音的性化或诱导性使用（零容忍）。
3. **合成语音必须披露**：可感知提示（播放器标注“AI 语音”/首启声明/音轨起始提示），不得声称真人配音；语音包内附 `LICENSE` 与来源、模型、日期、音色。
4. **TTS 条款未确认前**：不得把该 TTS 输出随包分发（本项目 18 个 DeepSeek TTS WAV 正处此状态，见 `THIRD-PARTY.md` §2）。

## 4. 形象替换

1. **允许**：原创形象／CC BY-NC-SA 素材／获授权素材；对官方角色做修改（CC BY-NC-SA 生效后）须署名 + 注明修改 + 不暗示背书。
2. **禁止**：使用他人 IP（含其他 orca/鲸鱼拟人角色、动漫角色、品牌吉祥物）；使用 DeepSeek 官方形象/Logo/鱼形标识；把官方角色改成 R18/仇恨/政治宣传形象并以“官方版”传播。
3. **必须**：标明原角色与作者、修改内容；**不得**移除 AI 标识/署名/水印；不得用“官方新形象/官方二版”命名或宣传。
4. AI 生成形象：披露生成工具与日期；不得把 AI 图登记为自己原创手绘；不得用未授权参考图/风格词锁定他人可识别风格（相似度风险，见 [LEGAL-IP-ORCA](../research/LEGAL-IP-ORCA.md)）。

## 5. 行为/参数与 UI

1. 行为只允许声明式数据：状态、权重、冷却、tag 退化链；不得携带表达式/代码/URL/网络请求。
2. UI 皮肤不得：遮挡许可与非官方声明、AI 标识、隐私同意与安全提示；不得伪装成官方系统提示；不得植入广告/打赏诱导伪装成功能。
3. 任何替换不得改变：签名校验、付费校验、遥测默认关闭、权限最小化等安全默认值。

## 6. 必须保留（removal = 违规）

- 根目录 `LICENSE` / `LICENSE-COMMERCIAL.md` / `NOTICE` / `LICENSE-ART`（随包分发）；
- 原作者、原许可、修改说明、`CREDITS`/TASL 行；
- AI 披露：`ai.status`/`ai.tool`、显式标识（角落“AI 生成”）、隐式元数据；
- 非官方声明与“与 DeepSeek 无关联”句；
- 签名与哈希、包 id/版本、兼容性字段；
- 安全提示、隐私同意、下架/举报入口。

## 7. 禁项汇总

恶意代码/脚本；绕过或伪造签名；真人声音克隆；未授权音源/影视音频；他人 IP 与商标；移除署名/AI 标识/许可；冒充官方或“官方版本”；把 `ai.status` 伪填 `none`；用替换包分发违法/NSFW 内容；要求用户关闭校验。

## 8. 声明与执行

1. 每个替换包必须附声明（字段见 [DECLARATION-TEMPLATES/README](./DECLARATION-TEMPLATES/README.md)）：作品名/作者/许可/素材来源/AI 披露/兼容版本/联系方式/禁项。
2. 违反者：拒绝加载 → 下架 → 通报 → 必要时移交平台/机关；申诉见 [TAKEDOWN](./TAKEDOWN-AND-REPORTING.md)。
3. 本项目不承诺审查所有替换包；不为其背书；用户自担安装风险。
