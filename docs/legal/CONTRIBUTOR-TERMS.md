## 2. 机制选择（待律师拍板）

| 机制 | 内容 | 适用 | 优点 / 风险 |
|---|---|---|---|
| **DCO 1.1** | 提交时 `Signed-off-by`，声明有权按项目许可提交（https://developercertificate.org/） | 所有贡献的最低门槛 | 轻量；**不授予再许可权**，无法支撑“商业专有版” |
| **CLA**（现有模板） | 授予 PerryLink 永久、全球、非排他、免费、不可撤销的复制/改编/分发/再许可（含商业/专有）权利 + 专利许可 | 代码、需要再许可的素材 | 支撑双许可；贡献者可能抵触；须律师定稿 |
| **入站 = 出站许可** | 贡献即按该层出站许可授权（代码 PolyForm NC；美术 CC BY-NC-SA 4.0） | 社区美术/文档 | 简单；**不**赋予专有再许可权，商业版不能用 |

**建议（待律师）**：代码 + 核心美术用 **CLA + DCO sign-off 双轨**；社区可选美术/文档提供 **“入站 CC BY-NC-SA 4.0”** 通道；两条通道的贡献在 `CREDITS.md` 分别标注，避免混同。**不得**要求贡献者接受与出站许可冲突的条款。

## 3. 入站许可矩阵

| 贡献类型 | 入站许可（建议） | 必须声明 |
|---|---|---|
| 代码/脚本/配置 | CLA（含再许可）+ DCO | 无第三方代码；依赖与许可；AI 辅助情况 |
| 美术/像素/设定 | CLA 或入站 CC BY-NC-SA 4.0（二选一通道） | 原创/授权链；AI 工具；是否含第三方参考 |
| 音频/语音 | CLA 或明确许可 | 自录/授权；**TTS 模型与音色条款**；禁真人克隆 |
| 文档/翻译 | 入站 CC BY-NC-SA 4.0（建议） | 原创；引用来源 |
| 字体/图标/素材 | **原则上不接受**；例外须附许可全文 | 来源、许可、可再分发范围 |
| 数据/台账 | 同代码 | 不含个人信息/密钥 |

## 4. AI 辅助贡献披露（强制）

提交时在 PR 描述中回答（并在 `CREDITS.md`/`AI-PROVENANCE.md` 记录）：
1. 是否使用生成式 AI（是/否）；用了哪些工具/模型/服务（含版本/日期）。
2. 输入来源：自产 prompt/参考图？是否使用他人作品/角色/风格/声音作为输入？
3. 人工修改程度：直接采用 / 筛选 / 重绘 / 像素化 / 调色 / 重写。
4. 是否含第三方受保护表达；是否可确权。
5. 若 AI 部分无法确权：贡献者同意项目按“无版权/CC0 式”使用该部分，并允许项目决定是否披露（**须律师确认此条的效力**）。

禁止：AI 生成他人 IP/角色/真人肖像声音；用 AI 洗稿他人贡献；把 AI 输出伪称为手工原创；隐瞒 AI 使用。

## 5. 贡献者声明与保证

1. 贡献为原创，或已取得足够授权（附授权链）。
2. 不侵犯第三方著作权/商标/专利/肖像/隐私/商业秘密。
3. 不含恶意代码、后门、密钥、凭据、用户个人数据、Steamworks SDK、私钥。
4. 不含违反 [CONTENT-POLICY](./CONTENT-POLICY.md) 的内容。
5. 已按要求披露 AI 与第三方素材。
6. 已阅读并接受 CLA/DCO 与行为准则（CoC 待建）。

## 6. 署名、记录与撤回

1. 署名：`CREDITS.md` 追加 TASL 行；git 作者记录保留；AI 贡献另记 `AI-PROVENANCE.md`。
2. **撤回**：贡献者可在后续版本中请求移除其贡献（项目尽力配合替换/删除未来分发）；但**已生效的许可不可撤销**（CC BY-NC-SA 不可撤销；CLA 授予的权利不可撤销），已分发副本仍可被合法使用。
3. 争议：先协商；涉及权利瑕疵的贡献可被回滚并公告（不泄露个人信息）。

## 7. 无担保与责任

- 贡献按 “as is” 提供，无任何明示/默示担保（含不侵权担保之外的项目侧免责，具体条款律师定）。
- 贡献者对其贡献的合法性负责；因贡献引发第三方索赔，按 CLA 与法律处理。
- 项目方可拒绝/回滚/修改任何贡献（含无理由），不承担贡献者因此产生的损失。

## 8. PR 流程（工程侧）

1. `git commit -s`（DCO sign-off）；PR 描述附 CLA 接受记录（暂由维护者记录）。
2. 通过 `npm test` / `npm run validate:content` / `npm run build`；新引用需测试。
3. 新增素材：附许可、来源、sha256、AI 披露；更新 `art/assets.csv`（`license`/`source_sha` 非 TBD）。
4. 不得提交：`<private-keys>/`、`refs/`、Steamworks SDK、`rustup-init.exe` 类第三方二进制、生成缓存。
5. 内容包/角色包贡献：走 [DLC-AND-PLUGIN-TERMS](./DLC-AND-PLUGIN-TERMS.md) 与校验 CLI。
