## 1. 谁用哪个模板

| 发布者/场景 | 用哪个模板 | 必须同时展示 |
|---|---|---|
| DLC/角色包/内容包（免费或收费） | **A** | 包内 `NOTICE.md` + 详情页 + manifest 字段 |
| 插件/渲染器（当前仅第一方；未来第三方按新政策） | **B** | 下载页 + About + 兼容性说明 |
| 同人图/文/视频/直播/周边 | **C** | 作品简介/置顶/包装 + 非官方声明 |
| 动作/声音/形象/行为/UI 替换包 | **D** | 包内声明 + 详情页 + 兼容版本 |

## 2. 字段字典（A/B/D 必须逐项填写；C 至少填 1–7、9–11）

| # | 字段 | 填写要求 | 示例 |
|---|---|---|---|
| 1 | 作品名 | 不得含“官方/正版/认证/授权”字样；不得用产品名/角色名冒充官方 | `珊瑚礁扩展包` |
| 2 | 类型 | 内容包/角色包/插件/替换包/同人（子类型） | `Character Pack (FCI 0.2)` |
| 3 | 作者/团队 | 真实可识别身份或稳定笔名 + 责任主体 | `<作者名>` |
| 4 | 联系方式 | 真实可达（用于下架/投诉/申诉） | `<email 或主页>` |
| 5 | 作品许可 | **SPDX 标识 + 许可链接**；自定义须给全文 | `CC-BY-NC-SA-4.0` + 链接 |
| 6 | 素材来源 | 逐项来源/作者/许可（含字体/音频/参考图）；无第三方写“全部原创” | `bgm: <来源>, CC0` |
| 7 | AI 披露 | 是否使用 + 工具/模型 + 日期 + 输入来源 + 人工修改程度 | `图：<模型> 2026-11-15，重绘` |
| 8 | 兼容版本 | 宿主版本/`apiVersion`/`minRuntime`/`minBase`；测试过的平台 | `minRuntime 0.2.x` |
| 9 | 署名方式 | TASL 行 + 显示位置 | `CREDITS.md 第 N 行` |
| 10 | 禁项确认 | 逐条勾选（见 §3） | `☑ ☑ ☑ ☑` |
| 11 | 非官方声明 | 必须含“非官方/无关联/无背书” | 见 §3 块 ① |
| 12 | 日期/版本/哈希 | 发布版本 + 包 sha256/签名指纹 | `v0.1.0 · sha256:…` |

## 3. 必填文本块（**不得删改**）

**① 非官方声明（中英）**
```text
本作品为第三方/同人内容，非官方，与 PerryLink 及 DeepSeek（深度求索）无任何关联、合作、授权或背书关系。
This is unofficial third-party/fan content, not affiliated with, endorsed by, or authorized by PerryLink or DeepSeek.
```

**② AI 生成披露（若适用）**
```text
本作品的部分/全部内容由生成式 AI 辅助生成（工具/模型：<…>；日期：<…>；人工修改：<…>），已按适用规则添加显式与隐式标识。
Part or all of this work was generated with generative AI assistance (<tool/model>, <date>; human edits: <…>) and is labeled accordingly.
```

**③ 禁项与责任块（A/B/D 必含）**
```text
发布者声明并保证：本包不含可执行代码/恶意代码/自动更新器；不含来源不明或未授权素材；不含他人 IP、真人声音克隆、未授权音源；
不删除/不伪造许可、署名、AI 标识与非官方声明；不冒充官方或“官方认证”；不违反内容政策零容忍项。
违反者由发布者承担全部责任，本项目可拒绝加载/下架/封禁。
```

## 4. 发布前自检（10 条）

- [ ] 1 非官方声明在包内 + 详情页都出现；2 无“官方/授权/认证”字样；3 许可字段是 SPDX + 链接；4 素材逐项有来源；5 AI 披露真实且与 manifest `ai` 字段一致；6 兼容版本已声明；7 联系方式可送达；8 包内 `LICENSE`/`NOTICE`/`CREDITS` 齐全；9 无他人 IP/商标/真人克隆音源；10 签名/哈希已生成，未要求用户关闭校验。
- 校验命令：`node scripts/validate-character.mjs --strict`（角色包）；内容包校验见包规范；失败即不得发布。

## 5. 规则

1. 不得删除/改写“非官方声明”“禁项与责任”“AI 披露”三个块；可在其后追加更严格的自律条款。
2. 不得用模板制造“官方授权”外观；不得把模板原文当作项目方对你作品的背书。
3. 模板不替代你的法务义务：你仍需自行确认素材许可、平台规则与当地法律。
4. 模板版本：本文件 2026-11-15 草案；项目方更新后请同步使用最新版（看 `变更记录`）。
