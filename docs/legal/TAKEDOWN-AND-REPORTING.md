## 1. 举报类型与受理范围

| 类型 | 示例 | 我方受理 | 备注 |
|---|---|---|---|
| 版权/商标侵权 | 盗用官方美术/角色包、冒用名称/Logo、抢注后反向投诉 | ✅ | 需权利证明；我方无权处理他人平台内容，转交平台 |
| 肖像/隐私/名誉 | 真人换脸、泄露个人信息、诽谤 | ✅（优先） | 涉安全风险可先临时下架 |
| 违法/有害内容 | 未成年人性化、色情、仇恨、暴力、诈骗 | ✅（**零容忍**） | 同时报告平台/主管机关 |
| 恶意包/安全 | 恶意代码、窃密、伪造签名 | ✅ | 走安全渠道可先隔离 |
| 冒充官方 | 假“官方”账号/店铺/公告 | ✅ | 可请求平台处置 |
| 一般内容争议/差评 | 观点批评、非官方同人 | ❌ 不处理 | 不审查批评；涉 §2 禁项除外 |
| 许可/署名争议 | 署名缺漏、许可不符 | ✅ | 优先补正而非下架 |

## 3. 通知材料清单（缺项会拖慢处理）

1. **通知人身份**：姓名/机构、联系方式、与权利的关系；代理须附授权委托书。
2. **权利基础**：著作权登记/商标注册号、首次发布记录、授权链、原创证明（源文件/时间戳/sha256）。
3. **侵权定位**：具体 URL/包 id/版本/`sha256`/截图/时间；逐项对应（不要只给一个笼统链接）。
4. **请求**：删除/下架/断开链接/停止传播等具体动作。
5. **真实性声明**：声明材料真实、善意、愿承担错误通知的法律责任；同意我方将材料转交被投诉方（涉隐私可说明）。
6. **联系方式有效性**：用于核实与结果反馈。

> 参考法律框架（**非**法律意见）：《民法典》第 1194–1197 条网络侵权“通知—反通知”规则（http://www.npc.gov.cn/npc/c30834/202006/75ba6483b8344591abd07917e1d25cc8.shtml）；《信息网络传播权保护条例》通知删除规则（国家法律法规数据库 https://flk.npc.gov.cn/）。**错误通知造成损害可能承担侵权责任**（《民法典》第 1195 条第 3 款），请勿滥用。

## 4. 处理流程与内部目标时限（非承诺）

| 步骤 | 动作 | 内部目标 |
|---|---|---|
| S1 收件确认 | 自动/人工回执，补材料清单 | 3 个工作日 |
| S2 初审 | 判断类型/管辖/是否属我方渠道；紧急（T1/安全）立即升级 | 10 个工作日 |
| S3 临时措施 | 明显侵权/违法/安全风险 → **先临时下架/隔离**；争议性内容快速处置 | 初审后 5 个工作日 |
| S4 通知被投诉方 | 转交材料要点，给申辩机会（隐私信息脱敏） | 与 S3 同步 |
| S5 申辩审查 | 综合双方材料与法律意见 | 10 个工作日 |
| S6 终局 | 恢复/永久下架/封禁/转平台；书面告知双方理由（不泄露他人隐私） | 20 个工作日 |
| S7 归档 | 记录处理结果、证据、是否需律师 | 结案后 30 日内 |

## 5. 临时下架与反通知（谨慎）

1. **临时下架**不等于认定侵权：目的是止损与调查；恢复须有明确结论。
2. **反通知**：仅在核实“通知明显错误/已获授权/属合理使用（法定情形）”后接受；**本仓没有 DMCA 式自动恢复程序**，不承诺时间与结果；反通知材料与 §3 同等要求。
3. 反通知后仍争议：建议双方走平台程序/律师函/诉讼；我方不充当裁判。
4. **不得因反通知而泄露原通知人身份/隐私**（法律要求除外）。
5. 对**重复侵权者/恶意发布者**：永久拒绝服务（封禁发布者、列入黑名单）。

## 6. 违规处理（对发布方）

| 级别 | 情形 | 动作 |
|---|---|---|
| L1 | 署名/许可字段缺漏 | 通知补正，限期内未改则下架 |
| L2 | 违反内容政策（非 T1） | 下架 + 警告；重复则封禁 |
| L3 | T1 零容忍 / 恶意代码 / 冒充官方 / 严重侵权 | **立即下架 + 封禁 + 报告平台/机关** |
| L4 | 伪造签名/证据、恶意举报 | 永久封禁 + 保留追责 |

## 7. 滥用举报

- 明显虚假/恶意/骚扰性通知：驳回并留存记录；造成损失的可依《民法典》主张责任。
- 同一通知人反复提交无依据通知：限制受理并要求补充材料。
- 我方人员的错误处理：内部复核 + 更正公告；涉及重大权益的转律师。

## 8. 证据与隐私

1. 投诉材料仅用于处理争议；按 PIPL 最小必要保存，结案后按内部期限删除（律师定）。
2. 公开处理公告须脱敏（不公开个人信息、私密影像、未生效法律意见）。
3. 涉刑事线索（CSAM、诈骗、威胁人身安全）→ 依法向公安机关/平台报告，不自行“私了”。
